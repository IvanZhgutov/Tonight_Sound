 Базовая концепция

  Палитра построена на тёмной космической теме с акцентами холодных синих оттенков. Основа — глубокие фиолетово-синие тона, создающие ощущение ночи и студийной атмосферы. Акценты — яркие голубые и циановые цвета,
  которые выделяют активные элементы и создают контраст.

  ---
  1. Фоны (Background)

  Основной фон страницы

  background: linear-gradient(to bottom, #171324, #111111)
  Назначение: Фон всего приложения
  Особенности: Плавный градиент от тёмно-фиолетового к почти чёрному — создаёт глубину и объём

  Фон календарной карточки

  --bg-calendar-1: #2B2B51  /* верх градиента */
  --bg-calendar-2: #0B0A1D  /* низ градиента */
  Назначение: Основной контейнер календаря
  Особенности: Приглушённый фиолетовый градиент с прозрачностью 70% — не перебивает содержимое

  Фон боковых квадратов (cards)

  --bg-square-1: #110222  /* верх */
  --bg-square-2: #181033  /* низ */
  Назначение: Карточки выбранных дней справа
  Особенности: Самые тёмные оттенки — создают визуальное углубление

  ---
  2. Акцентные цвета (Accents)

  Основной акцент — ярко-голубой

  --day-border: #00BBFF
  --scroll-bg-thumb: #00BFFF
  Назначение: Обводки активных элементов, скроллбар
  Особенности: Самый яркий цвет палитры — привлекает внимание, используется для границ и свечения активных дней

  Активные состояния — интенсивный синий

  --bg-button-active: #0048FF
  --time-border: #005DC8
  --square-title-span: #005CC6
  Назначение: Кнопка "Далее", обводки выбранного времени, названия месяцев
  Особенности: Насыщенный синий — показывает активность и кликабельность

  Hover-состояния — светло-голубой

  --time-border-hover: #177cf0
  --svg-close-hover: #00ccff
  --border-button-inactive-hover: #00a2ff
  Назначение: Подсветка при наведении
  Особенности: Светлее базового акцента — даёт обратную связь на взаимодействие

  ---
  3. Интерактивные элементы

  Кнопки дней календаря

  - По умолчанию: #4C4E70 — нейтральный серо-фиолетовый
  - Сегодня: #081431 — тёмно-синий с голубой обводкой и свечением
  - Активный день: #241A7C — насыщенный фиолетовый с ярким свечением
  - Выбранный день: #243560 — приглушённый синий

  Особенности: Все активные состояния имеют box-shadow с цветом кнопки — создаёт эффект свечения

  Кнопки времени

  - По умолчанию: #4C4E70 — совпадает с днями для единообразия
  - Активное время: #07032D — почти чёрный фон с яркой синей обводкой #005DC8

  Особенности: Выбранное время выделяется контрастом тёмного фона и яркой границы

  ---
  4. Границы (Borders)

  Градиентная обводка календаря

  --border-calendar-1: #AAA8BF  /* верх */
  --border-calendar-2: #433E54  /* низ */
  Назначение: Рамка вокруг календарной карточки
  Особенности: Тонкий градиент от светло-серого к тёмно-фиолетовому — выделяет контейнер, не перегружая

  Обводки квадратов

  --border-square: #003D83
  Назначение: Рамки карточек дней
  Особенности: Тёмно-синий — достаточно контрастен, но не отвлекает

  ---
  5. Текст и иконки

  Основной текст

  --square-title-number: #FFFFFF  /* день (число) */
  --color-square-accent: #FFFFFF  /* акцентный текст */
  Назначение: Заголовки, числа дней, основной контент
  Особенности: Чистый белый — максимальная читаемость

  Вторичный текст

  --square-color-gray: #4C4E70  /* неактивный/подсказки */
  --color-months: #9CCAFF         /* список месяцев */
  Назначение: Подсказки, неактивные элементы, названия месяцев
  Особенности: Приглушённые оттенки — создают визуальную иерархию

  Статусные цвета

  --square-color-green: #27DD97  /* успешное состояние */
  --svg-close: #0077FF            /* иконки закрытия */
  Назначение: Индикация состояний, действия
  Особенности: Зелёный для позитивных статусов, синий для действий

  ---
  6. Скроллбары

  --scroll-bg-track: #003D83  /* трек */
  --scroll-bg-thumb: #00BFFF  /* ползунок */
  Особенности: Ползунок использует акцентный голубой — виден, но не отвлекает

  ---
  Принципы использования

  1. Глубина через градиенты — все крупные блоки используют вертикальные градиенты от светлого к тёмному
  2. Свечение для активности — box-shadow с цветом элемента создаёт эффект подсветки
  3. Контраст для взаимодействия — активные элементы имеют высокий контраст (тёмный фон + яркая обводка)
  4. Единообразие нейтральных состояний — #4C4E70 используется и для дней, и для времени
  5. Прозрачность для слоёв — color-mix() добавляет полупрозрачность без новых переменных

  - Новые фоны: Оставаться в диапазоне #070320 — #2B2B51 (почти чёрный → серо-фиолетовый)
  - Ошибки/предупреждения: Можно добавить #FF4444 для ошибок, #FFB800 для предупреждений
  - Успех: Уже есть #27DD97 (зелёный)
